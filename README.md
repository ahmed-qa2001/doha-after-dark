# Doha After Dark

Doha After Dark is a UDST Practicum project that combines digital storytelling, location-based discovery, multimedia content, and intelligent features into an interactive platform focused on nighttime Doha.

## Project Objectives

The platform will include:

- Interactive Night Map
- Location-based stories
- Interviews and multimedia content
- Smart Crowd Prediction
- Recommendation Engine
- Content Management System
- Consent and permission management

## Pilot Locations

- Souq Waqif
- Doha Corniche
- Katara Cultural Village

## IT Development

The technical work includes:

- Application architecture
- Front-end development
- Back-end development
- REST API development
- Database design
- System integration
- Testing and deployment
